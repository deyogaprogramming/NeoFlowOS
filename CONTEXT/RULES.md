# Business Rules Document

## General Rules
- The application operates in two modes: Local (Offline) and Cloud (Online).
- Cloud mode requires user authentication via Google (Firebase Auth).

## Authentication & Authorization
- Users can only view, create, edit, and delete their own data.
- Data access is governed by Firestore Security Rules.

## Data Validation Rules
- **Idea**: Must have a title, mood, niche, platform, and status.
- **Prompt**: Must have a title, structured layers, and a preset.
- **Reference**: Must have a title, link, and category.

## Visual DNA Rules
- Visual DNA acts as the core aesthetic constraint.
- Prompts and ideas generated by AI should align with the defined Visual DNA.

## UI/UX Rules
- The system must provide visual feedback when an AI action is in progress.
- Users must be able to customize the application theme (Dark/Light) and accent color.
